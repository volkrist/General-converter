# General Converter — Image Converter App for Android

**General Converter** is an Android image converter app built with Flutter. It helps users convert image files between common formats, preview the result, and save the converted file on the device.

## Description

General Converter is designed for users who need a simple mobile tool for image format conversion. The app provides a direct workflow: select an image, choose the target format, convert the file, preview the result, and save it.

The project is also part of a wider ecosystem of tools, web services, mobile apps, security projects, and automation products developed under the Volkrist GitHub profile.

## Features

- Android image conversion app
- Image picker flow

## Supported Image Formats

The project documentation includes support for these image formats:

- JPG / JPEG
- PNG
- WebP
- HEIC
- GIF
- TIFF
- AVIF
- BMP

Support may depend on the current Android build, device capabilities, and package-level format support.
