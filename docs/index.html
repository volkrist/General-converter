General Converter — Android Image Converter App

General Converter is a Flutter Android app for converting image files between popular formats. Users can select an image, choose a target format, convert, preview, and save the result directly on the device.

The app is built for fast mobile image conversion and supports common workflows such as JPG to PNG, PNG to JPG, WebP conversion, HEIC conversion, AVIF conversion, TIFF conversion, GIF conversion and BMP conversion.

What is General Converter?

General Converter is an Android image converter application created for people who need a simple way to change image formats without using heavy desktop software. It focuses on a clear mobile flow: pick an image, select the output format, run conversion, check the preview and save the converted file.

The project is developed with Flutter and Dart. It is part of a wider software ecosystem that includes mobile apps, web projects, backend services, automation tools and security-related products.

Common Use Cases

  • Convert JPG images to PNG for better transparency workflows.
  • Convert PNG files to JPG for smaller sharing or upload size.
  • Convert WebP images for compatibility with older websites or services.
  • Convert HEIC photos from mobile devices to more widely supported formats.
  • Prepare images for websites, marketplaces, social media and documentation.
  • Quickly save converted files directly from an Android phone.
